# 高保真原型 · 默认设计规范

> 本文件是 `prd-designer` 产出高保真原型时的**默认设计规范**：用户调用角色时**未传入**设计规范，就按本文件执行；**传入了新的设计规范**（文件路径 / Figma / 文字描述），则以传入的为准，本文件仅在新规范未覆盖的维度上兜底。
> 结构分两层：**§1 ~ §3 通用层**（基调、色彩、字体——所有载体共用）+ **§4 载体预设**（扩展弹窗 / 移动 App / PC Web，按需求选一个）。评审壳层（§5)与载体无关，所有原型统一。
> 配套基底样式（可直接复制到原型目录起步）：`design-assets/business-chain.css`（评审壳层 + 扩展弹窗预设）、`design-assets/scheme-a-token-des.css`（弹窗主标题区 + 预估变动区）。壳层部分对所有载体通用；其他载体的还原层按 §4 对应预设自建。

## 1. 设计基调（通用）

- 风格：浅色、克制、信息层级靠字号 / 字重 / 灰阶拉开；品牌色只用于强调与可点击元素，不大面积铺色。
- 原型页面分两层：**评审壳层**（导航、场景列表、说明区——给评审者看）与**载体还原层**（目标界面本体——1:1 还原线上 / 目标态）。两层视觉分离，壳层不得影响载体还原层的尺寸与样式。
- **载体由需求决定，不预设立场**：扩展 / 小窗类产品用弹窗预设，移动端需求用 App 预设，后台 / 官网 / 工具站用 PC Web 预设。需求没写明目标载体时**先问用户**（询问优先原则），不默认弹窗。

## 3. 字体与排版（通用）

- **载体还原层**：`'HarmonyOS_Sans','PingFang SC','Noto Sans SC',-apple-system,sans-serif`；HarmonyOS Sans 三档字重（400 / 500 / 600）以 `@font-face` 从 `_shared-assets/fonts/` 本地加载。目标产品有自有品牌字体时以传入规范为准。
- **评审壳层**：`'PingFang SC','Noto Sans SC',-apple-system,BlinkMacSystemFont,sans-serif`。
- 数字一律 `font-variant-numeric: tabular-nums`；代码 / key 用 `SFMono-Regular, Menlo, monospace`。
- 字号阶梯（弹窗 / 移动端基准，PC Web 按 §4.3 上浮）：页头 16/600 · 区块主标题 17/500 · 列表重点 15/500 · 字段行 14 · 副文案 13 · 辅助与标签 12。

## 4. 载体预设（按需求选一个）

### 4.1 扩展弹窗 / 小窗（源自线上产品确认页实测，最完整的预设）

**360 × 600 px** 白底卡片，圆角 12px，投影 `0 12px 40px rgba(26,33,43,.18)`。自上而下固定分段，均 `flex-shrink:0`，中部内容区滚动：

| 区块 | 规格 |
|---|---|
| 页头 | 高 60px，居中，16px/600 `#1A212B`，底部 1px `#F7F7F7` 分隔线；可含行内 logo 20px |
| 信息栏 | 左右两端对齐的 12px 辅助信息行（左侧可点元素用品牌蓝 + 蓝色虚线下划线，超宽省略），左右 16px 内边距 |
| 主标题区 | 三行居中：辅助行（12px `#9BA4B6`，行内图标 14px）→ 主标题（17px/500 `#232C41`，重点 `.amt` 加重 600）→ 副标题（13px `#6D778C`，可空；警示态红色） |
| 列表 / 评估区 | 左对齐；小标签 12px `#9BA4B6` + 问号 tooltip（深色气泡 `rgba(26,33,43,.8)` + blur）；条目行 15px/500，行内图标 20px 圆形，正绿负红 |
| 详情 Tab | 双 Tab（15px，激活 600 `#232C41` + 3px 底条），面板内字段行 14px（标签 `#6D778C` / 值 `#232C41` 右对齐） |
| 底部按钮 | 双按钮各 50%，高 40px 圆角 6px：次按钮白底 + `#1A212B` 描边；主按钮 `#1A212B` 底白字；置灰态 `#C4C9D4` |

信息卡：`#F4F4F7` 底、圆角 6px、12px 字号。骨架态：渐变扫光条（`#F0F1F5 → #E7E9EF`），主按钮置灰、退出 / 拒绝类按钮始终可点。

### 4.2 移动 App（手机帧）

- 呈现：**375 × 812 px**（iPhone 基准）手机帧，圆角 28px 外框 + 顶部状态栏 44px（时间 / 信号电量模拟）+ 底部 Home 指示条 34px；内容区在帧内滚动。
- 导航：顶部导航栏高 44px（标题 17/600 居中，左返回右动作）；有底部 Tab 时高 49px + 安全区。
- 布局：页面左右边距 16px；卡片圆角 12px、白底、投影 `0 2px 12px rgba(26,33,43,.06)`；列表行高 ≥ 52px，分隔线 `#F7F7F7`。
- 按钮：主按钮全宽高 48px 圆角 8px；触控目标最小 44px。
- 字号沿用 §3 阶梯；正文 15px 起（移动端可读性下限）。

### 4.3 PC Web 页面

- 呈现：**1440 px 设计宽**；后台 / 工具类内容区 max-width 1200px 居中，营销 / 官网类可全宽分段。stage 内建议加浏览器窗口帧（顶部 36px 圆点 + 地址栏模拟）以示载体；整页场景多时可直接全宽平铺、场景间锚点切换。
- 导航：顶部导航高 64px 白底 + 1px 底线；后台类左侧栏宽 220px。
- 布局：12 栅格、栅格间距 24px；卡片圆角 12px、白底、1px `#E1E5EB` 描边或浅投影；区块间距 24 / 32px。
- 字号在 §3 阶梯上整体上浮：页面主标题 22 ~ 24/600，区块标题 18/600，正文 14，辅助 12 ~ 13。
- 表格：表头 `#F7F8FA` 底 12px/600，行高 44px，1px `#E8EBEF` 行分隔；hover `#F7F8FA`。
- 按钮：高 36px（表单内）/ 40px（页面级）圆角 6px，主按钮品牌蓝或 `#1A212B`（同一原型内统一取一种）。

> 其他载体（平板、TV、小程序等）：以最接近的预设为基础，帧尺寸按目标设备调整，并在原型的「模板与主文案」文档里注明取值依据。

## 5. 评审壳层结构规格（所有载体统一）

| 组件 | 规格 |
|---|---|
| 顶部导航 `cross-nav` | fixed 顶部高 36px，白底 95% + blur，页签 11px；激活态 `#E8EAFF` 底 + 品牌蓝字 + `#C5CAFF` 边框；禁用态删除线 |
| 链路条 `journey` | 页头下方横向节点链：节点 13px 圆角 8px 白底描边，激活态品牌蓝底白字 + 蓝色投影，节点间箭头 `→`（`#A2A8B3`），可横向滚动 |
| 左侧场景列表 `scenes-list` | 宽 200px 白底 sticky，场景按钮 12.5px 圆角 6px，激活态品牌蓝底白字；分组小标 12px/600，子场景缩进带 `├` / `└` 树形前缀 |
| 中部舞台 `stage` | 弹性居中放载体帧（弹窗卡片 / 手机帧 / 浏览器帧），上方场景标题 15px/600 + 副题 11px；PC Web 整页场景可占满中部 |
| 右侧说明区 `scene-desc` | 宽 640 ~ 702px（小视口降档）白底 sticky 滚动：场景头（`#1A212B` 深底白字卡 + 场景 ID 徽标）、小节 h3 13px/600 带下边线；载体为 PC Web 且横向空间不足时，说明区可改为场景下方折叠面板 |
| 说明区内容块 | 文案块 `copy`（左 3px `#1A212B` 边条）· 警示块 `warn`（`#FFF8E6` 底 + 橙边条）· 逻辑卡 `logic-card`（`#F0F1FF` 底 + 品牌蓝边条）· 埋点块 `ga-event`（灰边条 + mono key）· 对照表 `diff-table`（1px `#E4E6EB` 全框线，表头 `#F7F8FA`）· 标签 `new-tag`（粉底）/ `reuse-tag`（灰底） |
| iframe 嵌入模式 | 场景底座页支持 `body.embed` 类：隐藏壳层全部组件，只留载体帧居中，供分类页 iframe 引用 |

## 6. 静态资源（通用）

- 共享资源集中在 `prototype/_shared-assets/`：字体（HarmonyOS Sans 三档）、产品 logo、行内图标（20px 圆形展示）、通用图标（问号、错误、刷新等 svg）。
- 全部本地引用，禁止外部 CDN / 网络字体（与原型模板高保真标准一致）。

## 7. 使用与覆盖规则

1. **先定载体**：从需求判断目标载体并选 §4 对应预设；判断不了就问用户，不默认弹窗。
2. 新原型起步：评审壳层与色彩 / 字体 token 直接复用 `design-assets/` 基底 CSS；载体为扩展弹窗时基底中的 popup 样式可整段复用，其他载体按 §4 预设自建还原层样式，**通用层不重写**。
3. 用户传入新设计规范时：载体还原层完全按新规范（含尺寸、色彩、字体）；评审壳层如新规范未提及，沿用本文件 §5，保持评审体验一致。
4. 与设计稿冲突时：页面布局与视觉层级以设计稿（Figma）为准，本规范回改并在 PRD 变更记录中注明（对应 PRD 模板 §12.2 的裁决口径）。
